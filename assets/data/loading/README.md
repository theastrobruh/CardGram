# Loading screen

Coloca aquí imágenes para el carrusel de bienvenida.

Formatos recomendados:
- `.webp` (mejor peso)
- `.jpg` / `.jpeg`
- `.png`

También puedes editar `manifest.json` para apuntar a cualquier imagen del proyecto.
Usa imágenes horizontales o full arts; se recortan a pantalla completa.
