# User shops

- `theastrobruh-cover.webp` → imagen/PNG transparente de la mini tienda.
- `theastrobruh-avatar.webp` → avatar del usuario.
- Formatos: PNG transparente o WebP.
- Para nuevos usuarios, añade `usuario-cover.webp` y `usuario-avatar.webp` y actualiza `makeExploreCreatorCard()` en `assets/js/hub.js`.
